# 第三方服务清单

**更新日期：2026 年 7 月 29 日**
**状态：筹备版草案，正式上线前会按实际接入服务更新。**

中国大陆版本会优先使用境内可用、可合规披露的第三方服务。以下为计划方向，不代表当前已全部接入。

| 服务类型 | 计划用途 | 可能处理的信息 | 说明 |
|---|---|---|---|
| 云服务器 | 部署后端 API 和静态官网 | 网络请求、账号数据、业务数据 | 计划使用境内云厂商 |
| 数据库 | 存储账号、日志、社区和会员数据 | 用户账号、训练记录、社区内容 | 计划存储于中国大陆境内 |
| 对象存储 | 存储头像、封面、图片、视频 | 用户上传媒体 | 通过服务端签名上传 |
| 短信服务 | 手机号登录、验证码、账号安全 | 手机号、验证码状态 | 正式接入后补充服务商 |
| 地图与 POI | 岩馆搜索、路线地图、地点展示 | 位置信息、搜索关键词 | 计划使用境内地图/POI 服务 |
| AI 模型服务 | 训练建议、AI 问答 | 用户主动输入、训练记录摘要 | 计划接入已备案模型 |
| 支付与订阅 | 会员订阅、订单状态 | 订单标识、订阅状态 | iOS 端受 App Store 规则约束 |
| 内容安全 | 社区内容审核、风险识别 | 帖子、评论、图片、视频 | 正式接入后补充服务商 |
| 消息推送 | 评论、关注、训练提醒 | 设备推送标识、通知内容摘要 | 正式接入后补充服务商 |
| 崩溃与日志 | 故障排查、稳定性分析 | 设备信息、错误日志 | 中国区优先使用境内方案或关闭境外上报 |

## 当前 GitHub Pages 站点说明

本网站当前托管在 GitHub Pages，用于产品展示、法律文本草案和迁移前维护。中国大陆正式服务上线前，官网会迁移至公司主体备案的独立域名和境内接入服务。

## 更新机制

第三方服务或 SDK 发生变化时，我们会更新本清单，并在必要时通过 App 内通知或网站公告提示用户。
